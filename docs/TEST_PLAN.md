# CRM 销售管理系统 — 功能测试清单

> 本文档用于 Docker 本地部署后的手动功能验证。

## 环境信息

| 服务     | 地址                           | 说明        |
| -------- | ------------------------------ | ----------- |
| Web 前端 | http://localhost               | PC 管理后台 |
| API 后端 | http://localhost:3000/api/v1/  | REST API    |
| API 文档 | http://localhost:3000/api/docs | Swagger UI  |
| MySQL    | localhost:3306                 | 数据库      |
| Redis    | localhost:6379                 | 缓存        |

## 十二、API 接口冒烟测试（可选）

使用 curl 或 Postman 测试：

```bash
# 1. 健康检查
curl http://localhost:3000/api/v1/health

# 2. 登录获取 Token
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 3. 客户列表（替换 YOUR_TOKEN）
curl http://localhost:3000/api/v1/customers?page=1&pageSize=10 \
  -H "Authorization: Bearer YOUR_TOKEN"

# 4. 商机列表
curl http://localhost:3000/api/v1/opportunities?page=1&pageSize=10 \
  -H "Authorization: Bearer YOUR_TOKEN"

# 5. 通话记录列表
curl http://localhost:3000/api/v1/call-records?page=1&pageSize=10 \
  -H "Authorization: Bearer YOUR_TOKEN"

# 6. 知识库文章列表
curl http://localhost:3000/api/v1/knowledge/articles?page=1&pageSize=10 \
  -H "Authorization: Bearer YOUR_TOKEN"

# 7. 客户公海池
curl http://localhost:3000/api/v1/customer-pool \
  -H "Authorization: Bearer YOUR_TOKEN"

# 8. 销售目标
curl http://localhost:3000/api/v1/sales-targets \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## 测试环境启动/停止

```powershell
# 启动（首次或代码有改动时加 --build）
docker compose up -d --build

# 查看状态
docker compose ps

# 查看日志
docker compose logs -f server    # 后端日志
docker compose logs -f web       # Nginx 日志

# 停止
docker compose down

# 停止并清除数据（重新初始化）
docker compose down -v
```

## 已知限制

1. **微信小程序**：需要微信开发者工具，不在 Docker 测试范围内
2. **AI 功能**：需要配置 DashScope/Claude API Key，无 Key 时 AI 相关功能不可用
3. **WebSocket 通知**：需要长连接，浏览器 F12 Network 可查看 ws 连接状态
4. **OSS 上传**：素材管理中的文件上传需要配置阿里云 OSS，本地环境不可用
5. **录音/ASR**：录音存储和语音转写需要外部服务配置
