# Project Standards

## Authority

These standards summarize current CRM project practice. They do not replace
source code inspection. When standards and code disagree, inspect the local
module and update the standard only after confirming the real project direction.

## Files

- `engineering-standards.md` - cross-package engineering rules.
- `language-standards.md` - TypeScript and naming expectations.
- `framework-standards.md` - NestJS, Vue, uni-app, TypeORM, and test patterns.
