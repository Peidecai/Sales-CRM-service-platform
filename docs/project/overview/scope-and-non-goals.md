# Scope And Non-Goals

## In Scope

- Maintaining and extending the CRM monorepo.
- Keeping backend, web, miniapp, and shared package contracts aligned.
- Preserving test and type-check baselines.
- Improving project governance docs when they reduce future ambiguity.

## Out Of Scope By Default

- Whole-system rewrites.
- Replacing the UI stack or backend framework.
- Committing the external Codex template pack into the product repo.
- Deploying to production without explicit user request.
- Treating old docs as authoritative without code or command verification.

## Boundaries

Broad changes to auth, audit, migrations, AI, payment, deployment, and
cross-package APIs require explicit planning and fresh verification.
