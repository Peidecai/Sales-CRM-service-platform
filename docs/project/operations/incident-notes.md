# Incident Notes

## Purpose

Use this file as the index for production incidents, severe local failures, or
release-blocking regressions in the CRM platform. Create a separate dated note
under `docs/project/operations/incidents/` if an incident needs detail.

## CRM Incident Note Template

```markdown
# YYYY-MM-DD CRM Incident Title

## Impact

Affected users, roles, package, module, endpoint, page, queue, provider, or
deployment target.

## Timeline

- HH:mm timezone - event

## Root Cause

Known root cause, suspected cause, or explicitly unknown.

## Mitigation

Code, config, data repair, rollback, or operational change.

## Verification

Commands, smoke checks, logs, or manual workflow evidence.

## Follow-Up

- owner / action / target date
```
