# 00 — 项目概述

## 产品定位

CRM Sales APP 是面向一线销售团队的移动端工具，提供客户管理、通话拨号、商机推进、跟进记录、业绩 PK 等核心功能，强调**离线可用**、**云呼叫中心(通话录音+AI分析)**、**语音速记**三大差异化能力。

与 PC Web 端的关系：

| 维度 | PC Web (`@crm/web`)            | APP (`@crm/miniapp`)                                                    |
| ---- | ------------------------------ | ----------------------------------------------------------------------- |
| 定位 | 管理驾驶舱，数据分析+系统设置  | 移动作战工具，外勤+通话+速记                                            |
| 用户 | Admin / Manager / Sales        | 以 Sales 为主，Manager 查看                                             |
| 场景 | 办公室，大屏操作               | 外出拜访、通话间隙、路途中                                              |
| 数据 | 全量，批量导入导出             | 精简，离线队列同步                                                      |
| 独有 | 审计日志、互联网获客、系统配置 | Push 推送、云呼叫中心(通话录音)、双卡拨号、GPS 签到、OCR 取号、语音速记 |

## 技术选型

| 层       | 技术                            | 说明                                    |
| -------- | ------------------------------- | --------------------------------------- |
| 框架     | **uni-app 3.x + Vue 3**         | 复用现有 miniapp 代码，一套代码多端编译 |
| 语言     | TypeScript 5.x (strict)         | 与全平台统一                            |
| 状态管理 | Pinia                           | 与 Web 端一致                           |
| HTTP     | `uni.request` 封装              | 非 axios，适配多端                      |
| 构建     | Vite 5 + uni-app plugin         | 编译到 mp-weixin / APP / H5             |
| 包管理   | pnpm workspace (`@crm/miniapp`) | monorepo 共享 `@crm/shared`             |

### 为什么选 uni-app 而非 React Native / Flutter

| 考量           | uni-app                          | React Native | Flutter    |
| -------------- | -------------------------------- | ------------ | ---------- |
| 现有代码复用   | **100%**（已有 13 页面 + 8 API） | 需重写       | 需重写     |
| 微信小程序支持 | 原生支持                         | 需额外方案   | 需额外方案 |
| 原生能力       | uni-app Plus 插件市场            | 原生模块     | 平台通道   |
| 团队学习成本   | **零**（Vue 3 技术栈）           | 需学 React   | 需学 Dart  |
| 性能           | 够用（WebView + 原生渲染）       | 较好         | 最佳       |

**结论**: 追求快速迭代、代码最大复用，选 uni-app 编译到 APP；后期性能瓶颈时可渐进切 React Native。

## 目标平台

| 平台       | 最低版本       | 说明             |
| ---------- | -------------- | ---------------- |
| iOS        | 12.0+          | iPhone 6s 及以上 |
| Android    | 6.0+ (API 23)  | 覆盖 98% 设备    |
| 微信小程序 | 基础库 2.15.0+ | 保留现有能力     |

## 与后端的关系

- 100% 复用现有 NestJS 后端 (`@crm/server`)
- 所有接口前缀 `/api/v1`，响应格式 `{ code, message, data }`
- JWT 认证，`deviceType: 'app'` 区分设备
- 新增后端模块：Push 推送 (`/api/v1/push`)、GPS 签到 (`/api/v1/check-in`)、云呼叫中心 (`/api/v1/cloud-call`)
