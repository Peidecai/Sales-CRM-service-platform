# 09 — UI/UX 设计规范

## 设计语言

| 维度 | 规范                                                       |
| ---- | ---------------------------------------------------------- |
| 风格 | 简洁商务风，与 PC 端 Element Plus 风格统一                 |
| 主色 | `#409EFF` (Element Plus 蓝)                                |
| 辅色 | `#67C23A` 成功 / `#E6A23C` 警告 / `#F56C6C` 危险           |
| 字体 | 系统默认 (-apple-system, "PingFang SC", "Microsoft YaHei") |
| 圆角 | 8rpx (卡片) / 12rpx (按钮) / 50% (头像)                    |

---

## 色彩体系

| 用途     | 色值      | 场景               |
| -------- | --------- | ------------------ |
| 主色     | `#409EFF` | 按钮、链接、选中态 |
| 成功     | `#67C23A` | 成交、已完成       |
| 警告     | `#E6A23C` | 待跟进、临期       |
| 危险     | `#F56C6C` | 丢单、过期、删除   |
| 文字主色 | `#303133` | 标题、正文         |
| 文字辅色 | `#909399` | 辅助信息、提示     |
| 分割线   | `#EBEEF5` | 列表分割           |
| 背景     | `#F5F5F5` | 页面背景           |
| 卡片背景 | `#FFFFFF` | 卡片/容器          |

## 组件库

基于 uni-app 内置组件 + 自定义业务组件：

### 基础组件

| 组件            | 说明                               | 使用场景           |
| --------------- | ---------------------------------- | ------------------ |
| TabBar.vue      | 自定义 TabBar (5 tab + 中心 "+")   | 全局导航           |
| SearchBar.vue   | 搜索框 + 筛选                      | 列表页顶部         |
| ListItem.vue    | 通用列表项 (图标+标题+副标题+箭头) | 客户/商机/跟进     |
| StatusTag.vue   | 状态标签 (颜色映射)                | 客户状态、商机阶段 |
| EmptyState.vue  | 空状态 (图标+文字+操作按钮)        | 列表无数据         |
| LoadMore.vue    | 加载更多 (滚动触底)                | 分页列表           |
| ActionSheet.vue | 底部操作面板                       | "+" 按钮、批量操作 |

### 业务组件

| 组件                 | 说明                           |
| -------------------- | ------------------------------ |
| CustomerCard.vue     | 客户卡片 (名称+状态+等级+电话) |
| OpportunityCard.vue  | 商机卡片 (名称+金额+阶段)      |
| FollowUpTimeline.vue | 跟进时间线                     |
| CallResultForm.vue   | 通话后记录表单                 |
| StatsCard.vue        | 数据统计卡片 (数字+趋势)       |
| SimSelector.vue      | SIM 卡选择器 (APP 专属)        |

## 交互规范

### 手势交互

| 手势 | 场景        | 操作                          |
| ---- | ----------- | ----------------------------- |
| 下拉 | 列表页      | 刷新数据                      |
| 上滑 | 列表页      | 加载更多                      |
| 左滑 | 列表项      | 显示操作按钮 (编辑/删除/拨号) |
| 长按 | 列表项      | 进入多选模式                  |
| 点击 | 卡片/列表项 | 进入详情                      |

### 反馈规范

| 操作     | 反馈                                                 |
| -------- | ---------------------------------------------------- |
| 加载中   | 页面中央 loading spinner                             |
| 提交成功 | `uni.showToast({ icon: 'success' })`                 |
| 操作失败 | `uni.showToast({ icon: 'none', title: '错误信息' })` |
| 删除确认 | `uni.showModal({ title: '确认删除？' })`             |
| 网络异常 | 顶部横幅提示 "网络连接异常"                          |
| 空数据   | EmptyState 组件 (图标+文字+操作按钮)                 |

### 加载策略

| 场景     | 方案                           |
| -------- | ------------------------------ |
| 首次加载 | 全屏骨架屏 (Skeleton)          |
| 下拉刷新 | uni-app 原生下拉刷新           |
| 滚动加载 | 滚动到底部触发 `onReachBottom` |
| 操作提交 | 按钮 loading 态 + 防重复提交   |

## 适配规范

### 屏幕适配

| 方案     | 说明                                          |
| -------- | --------------------------------------------- |
| 单位     | `rpx` (750rpx = 屏幕宽度)                     |
| 安全区   | `padding-bottom: env(safe-area-inset-bottom)` |
| 刘海屏   | `padding-top: var(--status-bar-height)`       |
| 最大宽度 | 750rpx (竖屏)，横屏不考虑                     |

### 暗黑模式 (v2.0 预留)

```scss
@media (prefers-color-scheme: dark) {
  page {
    background-color: #1a1a1a;
    color: #e0e0e0;
  }
}
```

### 无障碍 (Accessibility)

| 规则       | 说明                       |
| ---------- | -------------------------- |
| 最小触控区 | 88rpx × 88rpx (44pt)       |
| 对比度     | 文字/背景对比度 ≥ 4.5:1    |
| aria-label | 所有图标按钮添加无障碍标签 |
