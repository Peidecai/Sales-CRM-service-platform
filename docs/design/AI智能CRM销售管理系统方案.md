## 1. 项目概述

### 1.1 项目定位

基于 AI 驱动的智能 CRM 销售管理系统，集成客户管理、销售流程、呼叫中心、AI 分析和销售信息管理五大核心模块，同时配套微信小程序满足外勤销售人员的移动办公需求。

### 1.2 目标用户

- **销售团队**：外勤销售、电话销售、销售主管
- **管理层**：销售经理、区域总监、VP
- **运营支持**：客服人员、数据分析师

### 1.3 技术亮点

- AI 智能通话分析（语音转文字 + 语义理解）
- 客户画像自动生成与购买意向预测
- 微信小程序外勤管理（LBS 定位 + 拜访签到）
- 全链路销售流程数字化

## 3. 核心业务模块

### 3.1 客户管理中心

客户全生命周期管理，从线索获取到成交转化的完整闭环。

#### 功能清单

| 功能         | 描述                                        |
| ------------ | ------------------------------------------- |
| 客户信息管理 | 企业/个人客户建档，支持自定义字段           |
| 客户分级分类 | 按行业、规模、区域、意向等多维度分类        |
| 客户公海池   | 未分配/回收客户统一管理，支持领取和分配规则 |
| 客户查重     | 自动检测重复客户，防止撞单                  |
| 联系人管理   | 多联系人关联，决策链梳理                    |
| 跟进记录     | 时间线式跟进历史，支持多种记录类型          |
| 客户标签     | 灵活标签体系，支持自动打标                  |
| 客户导入导出 | Excel 批量导入/导出，字段映射               |

#### 客户状态流转

```
线索 → 潜在客户 → 意向客户 → 商机客户 → 成交客户 → 长期维护
  │                                              │
  └──────── 无效/流失 ← 回收至公海 ←──────────────┘
```

### 3.2 销售流程管理

从商机创建到成交的全流程可视化管理。

#### 功能清单

| 功能     | 描述                           |
| -------- | ------------------------------ |
| 商机管理 | 商机创建、跟进、阶段推进       |
| 销售漏斗 | 可视化漏斗，各阶段转化率分析   |
| 报价管理 | 产品报价单生成、审批流程       |
| 合同管理 | 合同创建、审批、签署、归档     |
| 回款管理 | 回款计划、到账确认、逾期提醒   |
| 销售目标 | 团队/个人目标设定与达成追踪    |
| 业绩排行 | 实时销售排行榜，激励竞争       |
| 审批流程 | 折扣审批、合同审批等自定义流程 |

#### 商机阶段

```
初步接触 → 需求确认 → 方案提报 → 商务谈判 → 赢单/丢单
   10%       30%        50%        70%       100%/0%
```

### 3.3 呼叫中心

集成电话外呼与通话管理能力。

#### 功能清单

| 功能     | 描述                             |
| -------- | -------------------------------- |
| 一键外呼 | 客户详情页直接拨打，自动记录     |
| 来电弹屏 | 来电自动匹配客户信息弹窗显示     |
| 通话录音 | 全量录音存储，支持在线播放回听   |
| 通话记录 | 通话时长、状态、备注统一管理     |
| IVR 导航 | 语音导航菜单配置                 |
| 坐席管理 | 坐席状态监控、分配策略           |
| 外呼任务 | 批量外呼任务创建与执行           |
| 通话统计 | 接通率、通话时长、高峰时段等分析 |

#### 通话处理流程

```
发起外呼 / 接收来电
        │
        ▼
  自动匹配客户信息
        │
        ▼
  通话中（自动录音）
        │
        ▼
  通话结束 → 录音存储至 OSS
        │
        ▼
  讯飞 ASR 语音转文字
        │
        ▼
  Claude AI 通话分析
        │
        ▼
  生成通话摘要 + 跟进建议
```

### 3.4 AI 智能分析

基于 Claude API 的深度 AI 赋能。

#### 功能清单

| 功能         | 描述                              |
| ------------ | --------------------------------- |
| 通话内容分析 | AI 自动提取通话关键信息、客户意向 |
| 客户画像生成 | 基于历史交互数据自动生成客户画像  |
| 购买意向预测 | AI 评估客户成交概率与优先级       |
| 话术推荐     | 根据客户特征和场景推荐最佳话术    |
| 销售预测     | 基于历史数据和漏斗预测未来业绩    |
| 异常预警     | 客户流失预警、跟进超时提醒        |
| 竞品分析     | 从通话内容提取竞品信息并汇总      |
| 智能报告     | 自动生成周报/月报/季度分析报告    |

#### AI 分析流程

```
数据输入                    AI 处理                    输出结果
─────────────────────────────────────────────────────────────────
通话录音文字    ──→   Claude API    ──→   通话摘要
客户交互历史    ──→   语义理解      ──→   客户画像
销售漏斗数据    ──→   模式识别      ──→   成交预测
跟进记录        ──→   趋势分析      ──→   跟进建议
```

## 5. 云端部署方案

### 5.1 推荐云服务商

**阿里云** — 国内市场占有率第一，生态完善，适合企业级应用。

### 5.2 资源规划（50-100 用户规模）

| 资源         | 规格            | 数量 | 用途                 | 预估月费   |
| ------------ | --------------- | ---- | -------------------- | ---------- |
| ECS 云服务器 | 4核8G           | 2台  | 后端应用服务（主备） | ~800 元/台 |
| RDS MySQL    | 4核8G 高可用版  | 1套  | 主数据库（主从）     | ~600 元    |
| Redis        | 2G 标准版       | 1套  | 缓存、会话管理       | ~200 元    |
| OSS 对象存储 | 按量计费        | 1个  | 录音、附件存储       | ~100 元    |
| SLB 负载均衡 | 标准型          | 1个  | 流量分发             | ~100 元    |
| CDN          | 按流量计费      | -    | 静态资源加速         | ~50 元     |
| SSL 证书     | 免费型 / 付费型 | 1套  | HTTPS 加密           | 0 ~ 200 元 |
| 域名         | .com / .cn      | 1个  | 系统域名             | ~60 元/年  |

### 5.4 扩展方案

当用户规模增长时：

| 规模          | 调整方案                                             |
| ------------- | ---------------------------------------------------- |
| 100-500 用户  | ECS 升配至 8核16G，RDS 升配，增加 Redis 至 4G        |

| 2000+ 用户    | Kubernetes 容器编排，分库分表，ElasticSearch 搜索    |

## 6. Agent Teams 开发工作流

利用 AI assistant 的 **Agent Teams** 实验功能，实现多智能体并行协作开发。

### 6.1 启用方式

```bash
# 设置环境变量启用 Agent Teams
export CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=true

# 启动 AI assistant
claude
```

### 6.2 开发阶段规划

#### 第一阶段：架构搭建（1-2 周）

**Team Lead 主导**，搭建项目基础架构。

```
Team Lead
   │
   ├── 初始化项目结构（前端 + 后端）
   ├── 配置数据库 Schema
   ├── 搭建 CI/CD 流水线
   ├── 配置 CLAUDE.md 项目规范
   └── 编写基础中间件（认证、日志、异常处理）
```

**关键文件 — CLAUDE.md 示例：**

```markdown
# CRM 项目开发规范

## 技术栈

- 前端：Vue 3 + TypeScript + Element Plus
- 后端：NestJS + TypeORM
- 数据库：MySQL 8.0

## 代码规范

- 使用 ESLint + Prettier
- API 遵循 RESTful 设计
- 所有接口需要编写单元测试

## 分支策略

- main：生产分支
- develop：开发分支
- feature/\*：功能分支

## 提交规范

- feat: 新功能
- fix: 修复
- docs: 文档
- refactor: 重构
```

#### 第二阶段：核心模块并行开发（4-6 周）

**Agent Teams 并行开发**，每个 Teammate 负责一个核心模块。


### 6.4 质量保障 — Hooks 配置

```jsonc
// .claude/settings.json
{
  "hooks": {
    "TeammateIdle": {
      "command": "npm run lint && npm run test",
    },
    "TaskCompleted": {
      "command": "npm run test:integration",
    },
  },
}
```

- **TeammateIdle**：每当 Teammate 完成一轮工作进入空闲状态时，自动运行 lint 和单元测试
- **TaskCompleted**：每当任务被标记完成时，自动运行集成测试

### A. 数据库核心表设计概要

| 表名            | 说明       | 核心字段                                           |
| --------------- | ---------- | -------------------------------------------------- |
| `customers`     | 客户主表   | id, name, type, industry, source, owner_id, status |
| `contacts`      | 联系人表   | id, customer_id, name, phone, email, position      |
| `opportunities` | 商机表     | id, customer_id, name, stage, amount, probability  |
| `contracts`     | 合同表     | id, opportunity_id, amount, start_date, end_date   |
| `call_records`  | 通话记录   | id, customer_id, user_id, duration, recording_url  |
| `ai_analysis`   | AI分析结果 | id, call_id, summary, intent_score, suggestions    |
| `visit_records` | 拜访记录   | id, customer_id, user_id, location, photos, notes  |
| `users`         | 用户表     | id, name, role, department, phone                  |

### B. API 接口规划

```
/api/v1/
├── /auth              # 认证相关
│   ├── POST /login
│   ├── POST /logout
│   └── POST /refresh-token
├── /customers         # 客户管理
│   ├── GET    /          # 列表（分页、筛选）
│   ├── POST   /          # 创建
│   ├── GET    /:id       # 详情
│   ├── PUT    /:id       # 更新
│   └── DELETE /:id       # 删除
├── /opportunities     # 商机管理
├── /contracts         # 合同管理
├── /calls             # 通话管理
│   ├── POST /dial        # 发起外呼
│   └── GET  /:id/analysis  # AI分析结果
├── /analysis          # AI 分析
│   ├── POST /portrait    # 生成客户画像
│   └── POST /predict     # 购买意向预测
├── /visits            # 拜访管理
│   ├── POST /check-in    # 签到
│   └── GET  /today       # 今日计划
└── /reports           # 报表
    ├── GET /sales-funnel
    ├── GET /performance
    └── GET /call-stats
```
