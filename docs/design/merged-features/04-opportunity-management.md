# 04 — 商机管理

> 合并来源: 本项目 Opportunity 模块 + 磐销云商机/签约功能

## 现有功能（本项目）

- [x] 商机 CRUD + 软删除
- [x] 阶段流转（LEAD → QUALIFIED → PROPOSAL → NEGOTIATION → CLOSED_WON/LOST）
- [x] 关联客户
- [x] 数据所有权
- [x] CSV 导出
- [x] 报价单（Quotation 模块）
- [x] 审批流（Approval 模块）

## 磐销云相关功能

- 商机类型数量显示（文件夹式展示各类型商机数量）
- 签单统计
- 商机阶段可视化

## 合并后功能清单

### 4.1 商机基础管理（增强）

| 功能            | 说明                | 状态     |
| --------------- | ------------------- | -------- |
| 商机 CRUD       | 创建/查看/编辑/删除 | 已有     |

### 4.2 销售漏斗（新增）

| 功能         | 说明                       | 状态     |
| ------------ | -------------------------- | -------- |
| 漏斗图可视化 | 各阶段商机数量/金额漏斗图  | **新增** |
| 阶段转化率   | 各阶段之间的转化率统计     | **新增** |
| 平均停留时间 | 商机在各阶段的平均停留天数 | **新增** |
| 漏斗对比     | 不同时间段/团队的漏斗对比  | **新增** |
| 阶段预警     | 停留超过N天的商机自动标记  | **新增** |

### 4.3 商机预测（新增）

| 功能           | 说明                     | 状态     |

| Pipeline 预测  | 预测本月/季度营收        | **新增** |
| 风险商机标记   | AI 识别可能丢单的商机    | **新增** |
| 预测准确度追踪 | 回溯预测与实际的偏差     | **新增** |

## 后端接口（新增部分）

| 接口                                 | 方法 | 说明          |
| ------------------------------------ | ---- | ------------- |

| `/api/v1/opportunities/forecast`     | GET  | Pipeline 预测 |
| `/api/v1/opportunities/:id/ai-score` | GET  | AI 成交概率   |
| `/api/v1/opportunities/stale`        | GET  | 停滞商机列表  |
