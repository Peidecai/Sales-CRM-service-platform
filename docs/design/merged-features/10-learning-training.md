# 10 — 学习与培训

> 合并来源: 本项目 Knowledge 模块 + 磐销云 学习园地 + 葵花宝典

## 现有功能（本项目）

- [x] 知识库文章管理（Knowledge 模块）
- [x] 文章分类（产品/话术/行业/FAQ/培训）
- [x] RAG 向量检索
- [x] Markdown 渲染
- [x] 文章审核流程

## 磐销云学习功能

- 企业论坛（帖子发布/讨论）
- 企业考试（在线考试）
- 微信营销（营销素材管理）
- 学习视频（视频教程）

## 后端接口（新增部分）

| 接口                                   | 方法           | 说明          |
| -------------------------------------- | -------------- | ------------- |
| `/api/v1/forum/posts`                  | GET/POST       | 帖子列表/发帖 |
| `/api/v1/forum/posts/:id`              | GET/PUT/DELETE | 帖子详情      |
| `/api/v1/forum/posts/:id/comments`     | GET/POST       | 评论          |
| `/api/v1/forum/categories`             | GET/POST       | 板块管理      |
| `/api/v1/exam/questions`               | GET/POST       | 题库管理      |
| `/api/v1/exam/papers`                  | GET/POST       | 试卷管理      |
| `/api/v1/exam/sessions`                | GET/POST       | 考试会话      |
| `/api/v1/exam/sessions/:id/submit`     | POST           | 提交答卷      |
| `/api/v1/exam/statistics`              | GET            | 考试统计      |
| `/api/v1/training/videos`              | GET/POST       | 视频管理      |
| `/api/v1/training/videos/:id/progress` | PUT            | 更新学习进度  |
| `/api/v1/training/tasks`               | GET/POST       | 学习任务      |
| `/api/v1/marketing/materials`          | GET/POST       | 营销素材      |
