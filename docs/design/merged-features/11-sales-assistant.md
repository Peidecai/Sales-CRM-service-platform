# 11 — 业务助手

> 合并来源: 本项目 Notification/Announcement/FollowUp 模块 + 磐销云业务助手

## 现有功能（本项目）

- [x] WebSocket 实时通知（Notification）
- [x] 公司公告（Announcement）
- [x] 跟进管理 + AI提醒（FollowUp）
- [x] 审批流（Approval）

## 磐销云业务助手功能

- 批注记录（主管对员工的批注/点评）
- 待办列表
- 公司公告
- 企业查询（企查查集成）
- 重复客户检测
- 业绩目标

## 后端接口（新增部分）

| 接口                                      | 方法       | 说明          |
| ----------------------------------------- | ---------- | ------------- |
| `/api/v1/todo`                            | GET/POST   | 待办列表/创建 |
| `/api/v1/todo/:id`                        | PUT/DELETE | 更新/删除待办 |
| `/api/v1/todo/:id/complete`               | PUT        | 完成待办      |
| `/api/v1/annotations`                     | GET/POST   | 批注列表/创建 |
| `/api/v1/annotations/by-employee/:userId` | GET        | 按员工查批注  |
| `/api/v1/notifications/settings`          | GET/PUT    | 通知偏好设置  |
| `/api/v1/announcements/:id/read-stats`    | GET        | 公告已读统计  |
