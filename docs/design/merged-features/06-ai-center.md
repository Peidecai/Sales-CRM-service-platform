## 后端接口（新增部分）

| 接口                                                 | 方法     | 说明                       |
| ---------------------------------------------------- | -------- | -------------------------- |
| `/api/v1/ai/copilot/chat`                            | POST     | Copilot 对话（增强版Chat） |

| `/api/v1/ai/employee-profile/:userId/growth`         | GET      | 成长曲线                   |
| `/api/v1/ai/customer-profile/:customerId`            | GET      | 客户AI画像                 |
| `/api/v1/ai/customer-profile/:customerId/nba`        | GET      | Next Best Action           |
| `/api/v1/ai/customer-profile/:customerId/churn-risk` | GET      | 流失预警                   |
| `/api/v1/ai/best-contact-time/:customerId`           | GET      | 最佳联系时间               |
| `/api/v1/ai/speech-templates`                        | GET/POST | 话术模板                   |
