- [x] APP 端（iOS + Android）

- [x] 离线队列

## 合并后方案

### 13.1 技术选型

| 方案              | 优势                          | 劣势                 |
| ----------------- | ----------------------------- | -------------------- |
| **React Native**  | 生态成熟、热更新、复用Web逻辑 | 性能不如原生         |
| **Flutter**       | 高性能UI、跨平台一致性        | 生态相对较新         |
| **uni-app → APP** | 复用现有代码最多              | 性能有限、原生能力弱 |

**已确定**: 选用 uni-app 3.x + Vue 3 编译 APP（iOS + Android），最大化代码复用，后期性能瓶颈时可渐进切换。
