# 03 — 客户管理

> 合并来源: 本项目 Customer 模块 + 磐销云 AI客户页

## 现有功能（本项目）

- [x] 客户 CRUD + 软删除
- [x] 数据所有权（SALES 只看自己）
- [x] 客户状态8态流转
- [x] 客户来源/类型/规模/等级/信用评级
- [x] 联系人管理（Contact 模块）
- [x] 跟进记录（FollowUp 模块）
- [x] 客户标签（CustomerTag 模块）
- [x] CSV 导出
- [x] 详情页（基本信息+商机+通话+跟进）
- [x] Redis 缓存

## 磐销云客户管理功能

- AI 通话录音关联
- 通话意向度显示
- 客户阶段可视化
- 商机管理关联
- 客户分组
- 签约促成
- AI 商务提醒
- 贷后服务
- 员工考核关联
- 录音上传
- 微信分析
- 谈判分析
- 回款追踪
- 批量操作（转公海/转让/转废弃站/转黑名单/批量分配责任人）
- 手机号显隐控制

## 后端接口（新增部分）

| 接口                                   | 方法                | 说明            |
| -------------------------------------- | ------------------- | --------------- |
| `/api/v1/customers/batch/transfer`     | POST                | 批量转让        |
| `/api/v1/customers/batch/to-pool`      | POST                | 批量转公海      |
| `/api/v1/customers/batch/to-blacklist` | POST                | 批量转黑名单    |
| `/api/v1/customers/batch/abandon`      | POST                | 批量废弃        |
| `/api/v1/customers/batch/assign`       | POST                | 批量分配        |
| `/api/v1/customers/batch/tag`          | POST                | 批量打标签      |
| `/api/v1/customers/groups`             | GET/POST/PUT/DELETE | 客户分组CRUD    |
| `/api/v1/customers/duplicates`         | GET                 | 重复客户列表    |
| `/api/v1/customers/duplicates/merge`   | POST                | 合并重复客户    |
| `/api/v1/customers/:id/360`            | GET                 | 客户360视图聚合 |
| `/api/v1/customers/:id/ai-profile`     | GET                 | AI客户画像      |
| `/api/v1/customers/:id/timeline`       | GET                 | 操作时间线      |
