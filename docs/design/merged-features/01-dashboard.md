## 合并后功能清单

### 1.1 数据概览卡片

| 卡片     | 数据                   | 来源      |
| -------- | ---------------------- | --------- |
| 今日通话 | 通话数/接通率/平均时长 | 已有+增强 |
| 今日客户 | 新增/跟进/转化数       | 已有+增强 |
| 本月业绩 | 签单金额/目标完成率    | 已有+增强 |
| 本月回款 | 回款金额/回款率        | **新增**  |
| AI 评分  | 个人今日通话评分/排名  | **新增**  |

### 1.2 图表区域

| 图表           | 说明                | 状态     |
| -------------- | ------------------- | -------- |
| 业绩趋势折线图 | 近30天签单/回款趋势 | 已有增强 |
| 销售漏斗       | 各阶段线索/客户转化 | **新增** |
| 团队排行榜     | 本月业绩 TOP10      | **新增** |
| 通话热力图     | 按小时分布的通话量  | **新增** |
