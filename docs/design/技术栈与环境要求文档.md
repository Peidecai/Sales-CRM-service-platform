## 6. 安全要求

| 安全域    | 措施                                                               |
| --------- | ------------------------------------------------------------------ |
| 认证      | JWT 双 Token 机制 (Access Token 2h + Refresh Token 7d)，RS256 签名 |
| 密码      | bcrypt 哈希存储，前端 RSA 加密传输                                 |
| 权限      | RBAC 角色权限模型（超级管理员/管理员/经理/销售），数据权限隔离     |
| HTTPS     | 全站 HTTPS，SLB SSL 卸载，HSTS                                     |
| XSS 防护  | ESLint 禁用 `v-html`，DOMPurify 消毒，CSP 响应头                   |
| CSRF 防护 | JWT Bearer Token 天然免疫 + X-CSRF-Token 双重保险                  |
| SQL 注入  | TypeORM 参数化查询，禁止原生 SQL 拼接                              |
| 限流      | API Gateway 限流中间件                                             |
| 日志审计  | 全量操作日志记录，阿里云 SLS 日志分析                              |
| 网络隔离  | VPC 安全组划分公网/内网子网，数据库仅内网可访问                    |
| 密钥管理  | 阿里云 KMS 加密敏感配置                                            |
| 逻辑删除  | 全表使用 `deleted` 字段软删除，数据可恢复                          |
