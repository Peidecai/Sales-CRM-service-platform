# P0-01 | 安全 | bcrypt salt rounds 从 10 改为 12
在文件 packages/server/src/modules/user/user.service.ts 中：
1. 在类顶部添加私有常量：private readonly BCRYPT_SALT_ROUNDS = 12
2. 将第 26 行和第 88 行的 bcrypt.hash(dto.password, 10) 改为 bcrypt.hash(dto.password, this.BCRYPT_SALT_ROUNDS)

# P0-02 | 安全 | 注册全局 ThrottlerGuard
在 packages/server/src/app.module.ts 中：
1. 添加 import { APP_GUARD } from '@nestjs/core' 和 import { CustomThrottlerGuard } from './common/guards/custom-throttler.guard'
2. 在 @Module 的 providers 数组中添加 { provide: APP_GUARD, useClass: CustomThrottlerGuard }

# P0-03 | 安全 | AI 端点添加独立频率限制
在 packages/server/src/modules/ai/ai.controller.ts 中添加 @Throttle({ default: { ttl: 60000, limit: 3 } }) 到 AI 生成方法
在 packages/server/src/modules/knowledge/knowledge.controller.ts 的 askQuestion() 方法添加 @Throttle({ default: { ttl: 60000, limit: 5 } })

# P0-04 | API | throw new Error 替换为 NestJS 内置异常
将 agent.controller.ts、recording.controller.ts、campaign.controller.ts 中的 throw new Error 替换为 NotFoundException、BadRequestException、ForbiddenException

# P0-05 | API | 修复双前缀路由 bug
修复 contact.controller.ts、customer-pool.controller.ts、custom-field.controller.ts、customer-tag.controller.ts 中重复的路由前缀

# P0-06 | API | 解决 call Controller 路由前缀冲突
将 call-callback.controller.ts 的 @Controller('call') 改为 @Controller('call-callback')
将 call-popup.controller.ts 的 @Controller('call') 改为 @Controller('call-popup')

# P0-07 | 安全 | 回调签名改用恒等时间比较 + 防重放
在 callback-signature.guard.ts 中使用 timingSafeEqual 进行签名比较
在 call-callback.controller.ts 中叠加 ReplayAttackGuard
